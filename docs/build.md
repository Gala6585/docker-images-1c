# Сборка

Подготовьте `.env` и локальные `.deb`, затем выполните `make validate` и
`make build-all`. Скрипты вычисляют корень независимо от текущего каталога.
По умолчанию фиксированный OneScript загружается из официального GitHub Release;
сборка требует конкретные `OSCRIPT_VERSION` и `OSCRIPT_SHA256`. Значения для нового
релиза берите из его официальных assets/digest. `INSTALL_OSCRIPT_FROM_LOCAL=true`
переключает сборку на локальный `.deb` для закрытой сети.
Для Allure рекомендуется задать `ALLURE_SHA256` из доверенного источника.

После сборки выполните три `make check-*`. Проверка намеренно не вызывает
`1cv8c /Version`, поскольку GUI-процесс может зависнуть в headless-среде.
