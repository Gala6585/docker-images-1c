# Архитектура

`1c-platform` содержит только Ubuntu 22.04, thin client `1cv8c`, Xvfb, DBus,
локаль, шрифты и библиотеки. `vanessa-runner` наследуется через `ARG BASE_IMAGE`
и добавляет OneScript/opm/vanessa-runner 2.6.1. `vanessa-runner-allure` наследует
второй слой и добавляет Java, Allure 2.29.0 и сценарии запуска. Поддержка команд
3.x намеренно отсутствует до отдельного профиля совместимости.

Неизменяемые теги включают полные версии всех компонентов. Короткие alias можно
добавить через `docker tag` после успешной проверки; они не заменяют основные.
